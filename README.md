# restream

📺 Sirius HD TV - Canlı Yayın
Bu repository, Sirius HD TV kanalının dünyaya açık, kesintisiz ve yüksek kaliteli (Full HD) yayın akışını barındırmaktadır. 
Yayın, profesyonel bir altyapı kullanılarak doğrudan izleyicilere sunulmaktadır.

🔗 Hızlı Erişim (M3U8)
Yayını VLC, PotPlayer veya diğer IPTV oynatıcılarda açmak için aşağıdaki direkt linki kullanabilirsiniz: 

https://raw.githubusercontent.com/Elvin4K/restream/refs/heads/pro4k/1siriustv.m3u8


🛠️ Yayın Teknik Özellikleri

Çözünürlük: 1920x1080 (Full HD)

Kare Hızı: 25 FPS (Sinematik akış)

Video Kodlayıcı: NVIDIA NVENC H.264 (Yüksek Kalite)

Ses: FFmpeg AAC

Bit hızı: Dinamik (6000 - 8000 Kbps arası stabilizasyon)


⚙️ Nasıl İzlenir?
VLC Media Player: Ortam -> Ağ Akışı Aç yolunu izleyin ve yukarıdaki linki yapıştırın.

IPTV Uygulamaları: Linki playlist (oynatma listesi) olarak ekleyin.

Tarayıcı: HLS destekli tarayıcı eklentileriyle doğrudan izleyebilirsiniz.
