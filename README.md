🛠️ Yayın Teknik Özellikleri
Senin sistem verilerine ve OBS ayarlarına dayanarak bu teknik detayları eklemek güven verir:

Çözünürlük: 1920x1080 (Full HD)

Kare Hızı: 25 FPS (Sinematik akış)

Kare Hızı: 60 FPS (Akıcı Gerçeklik)

Video Kodlayıcı: NVIDIA NVENC H.264 (Yüksek Kalite)

Ses: FFmpeg AAC

Bit hızı: Dinamik (6000 - 8000 Kbps arası stabilizasyon)

⚙️ Nasıl İzlenir?
VLC Media Player: Ortam -> Ağ Akışı Aç yolunu izleyin ve yukarıdaki linki yapıştırın.

IPTV Uygulamaları: Linki playlist (oynatma listesi) olarak ekleyin.

Tarayıcı: HLS destekli tarayıcı eklentileriyle doğrudan izleyebilirsiniz.
